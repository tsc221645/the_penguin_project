# Changelog

All notable changes to The Penguin Project will be documented here.

## [0.4.4] — Unreleased

- Corrected the release metadata and tag format after the failed `v0.4.1`, `v0.4.2`, and `v0.4.3` attempts.

## [0.4.0] — Unreleased

- Added the Phase 4 educational quiz with sourced explanations, animated answer feedback, and an approved-image identification question.
- Added reviewed quiz questions for additional species and source/image validation for quiz records.
- Added a species-specific habitat map and accessible region list to every penguin profile.
- Improved profile gallery framing and refreshed the site branding with the project logo and logo-based color palette.

## [0.1.0] — 2026-11-24

- Added the 18-species directory with verified Wikimedia Commons imagery and attribution records.
- Added species search, comparison, IUCN category guidance, and an accessible image carousel.
- Added the reviewed GBIF habitat map and tag-based GitHub Pages release pipeline.
- Updated the home collection to present all 18 species.

## Release notes format

Published releases use a `vMAJOR.MINOR.PATCH` tag and GitHub-generated notes. The package version must match the tag without the leading `v`.
